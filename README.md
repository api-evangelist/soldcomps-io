SoldComps.io provides an API delivering eBay sold price data for items across US, UK, and DE markets. It offers up to 200 sales per request, with free tier credits and paid plans for higher volume. The service returns median, middle range, and outlier‑filtered pricing information, helping businesses and resellers assess market values. Documentation, pricing, and blog resources are available on the site.

**Areas:** eBay · Pricing · Data · API · Marketplace
